以下は『東京市史稿』変災篇（1910年代刊、江戸〜明治初めの火災記録を集めた史料集）の国立国会図書館OCRからの抜粋です。OCRの誤りを含みます。
各事例について「対象の記述」が指す火事を本文から判断し、次の項目をJSONの配列で答えてください。推測で埋めず、本文から読めないものは null にしてください。

- id: 事例番号
- whole_fire: 対象の記述の長さ・幅が、一つの火事の焼失範囲全体を指すなら true、町ごと・区域ごとの一部分や複数の火事の合計なら false
- length_ken: 長さを間に換算した数（1里=36町、1町=60間、「半」は単位の半分、「三四町」のような幅のある数は中間）
- width_ken: 幅を間に換算した数
- length_is_nobe: 長さが「長延」など延べの長さと明記されていれば true
- width_is_average: 幅が「平均」と明記されていれば true
- wind: この同じ火事について本文に書かれた風の記述（原文のまま）。別の年月日の火事の記述は含めない
- start_time / end_time: この同じ火事の出火・鎮火の時刻の記述（原文のまま）
- note: 判断に迷った点を一文で

### 事例 1
対象の記述: 「長凡三十三丁餘、幅廣狹平均して四丁」
本文（OCR、前後を含む）:
目續き岩城升二月五日三年晴天、入なり屋の後なる高田放生寺の拜借地ニ在る見守番人の家炭團より出火して、烟屋西東ニ被り、一時よ燒ひろぶり、黑烟天を焦し、同町五丁目より一町まで、隼丁平川丁·山本町·谷町邊、又武家地多く燒け、定火消御役屋鋪·京極候·明石候·三宅侯·井伊侯·細川侯等の御屋鋪類燒ニ及び、藝州侯ハ別條なし。夫より黑田侯·内藤侯·九鬼侯·丹羽侯·柳澤侯より、外櫻田へ飛て、京極侯·木下侯·相良侯·御勘定奉行御役屋鋪·加藤侯·栃木侯·兼房丁·和泉丁·備前丁·伏見丁·鍛冶丁の邊、愛宕山本社·二王門·額堂·末社·別當所·末寺、同所麓東西大小名やしき一圓、眞福寺·天德寺·同門前·靑松寺へ燒込.增上寺ハ支院數宇燒け、神明社、濱の大久保候より、金杉橋、松平因州侯下屋鋪、其外柴井丁·宇田川丁·神明町·三島町·七軒丁·中門前·片門前·濱松町·新網丁·湊丁·西應寺·同朋丁·濱町·金杉一丁目より五丁目迄の町屋一圓、圓珠寺·正傳寺·安樂寺·德覺寺、其外此邊の寺院類燒して芝橋際迄濱手ニ至り、夜戌下刻漸々鎭火せり。會津侯·仙臺侯·新錢座ハ殘る。諸侯の藩邸五十二字、小名九十二宇、寺院十九宇の餘、町數五十七町なり。長凡三十三丁餘、幅廣狹平均して四丁の餘と聞く。燒死怪我人數ふるあらにと〓。-續武江年表五日年二月。○嘉永朝より西北大風、巳刻過、麴丁四丁目岩城呉服店裏町炭團屋より出火、岩城升屋ハ跡火ニ燒ケ、夫〓
