以下は『東京市史稿』変災篇（1910年代刊、江戸〜明治初めの火災記録を集めた史料集）の国立国会図書館OCRからの抜粋です。OCRの誤りを含みます。
各事例について「対象の記述」が指す火事を本文から判断し、次の項目をJSONの配列で答えてください。推測で埋めず、本文から読めないものは null にしてください。

- id: 事例番号
- whole_fire: 対象の記述の長さ・幅が、一つの火事の焼失範囲全体を指すなら true、町ごと・区域ごとの一部分や複数の火事の合計なら false
- length_ken: 長さを間に換算した数（1里=36町、1町=60間、「半」は単位の半分、「三四町」のような幅のある数は中間）
- width_ken: 幅を間に換算した数
- length_is_nobe: 長さが「長延」など延べの長さと明記されていれば true
- width_is_average: 幅が「平均」と明記されていれば true
- wind: この同じ火事について本文に書かれた風の記述（原文のまま）。別の年月日の火事の記述は含めない
- start_time / end_time: この同じ火事の出火・鎮火の時刻の記述（原文のまま）
- note: 判断に迷った点を一文で

### 事例 1
対象の記述: 「長サ平均一里三十丁餘、幅九丁半」
本文（OCR、前後を含む）:
島も燒。去ば此侯の別館靈岸島ニあるも燒にければ、下々の歎きを憐み、早く長屋作り與へ、餘寒のうれへなからしめよ、もし其用途つかへには、おのれ獨り衣食を厚ふすべけんやとて、御硯の下より黃金五百兩賜ひぬ。よりていとはやく長屋もたち、また夜具抔も疊給ひけれは涙こぼさぬもなかりしとぞ。-近世紀正月廿五日三年弘化大雪夕晴、不定風。過ル十五日八ツ半頃、本〓丸山本妙寺邊〓失火、西北之風烈敷、本〓通り加賀殿長屋向燒住居御住居ハ不燒湯島邊火口三方へ分レ、一口ハ御成小路、一口ハ御茶之水、聖堂ハ殘、學寮ハ燒失、駿河臺稻葉丹波守殿誼10〓正小川丁·三河丁邊る、鎌倉河岸通り、本丁·日本橋通り、四日市·江戶橋南へ一圓燒、材木丁·八丁堀·京橋迄、一方ハ筋違內·松平伊賀守殿○志須優田丁·傳馬丁·小網丁近邊夫〓北八丁堀·鐵砲洲·佃島燒拂候由。又風說こハ、深川·本庄へも飛火致、類燒之街談有之由。尤三屋鋪無別條段申來ル。二月朔日、雨天、晝前〓雪氣、夕風。去月十五六日江戶之火災追々相知ゆ處、火元ハ小石川片町續丸山阿部伊勢守로싱100正上ケ地、御代官筑山茂左衞門手附中村惣助地借一橋殿御住居勘定方勤坂本林平よ申者之由。類燒之場所凡長サ平均一里三十丁餘、幅九丁半、凡町數二百丁餘之由。將又深川本庄ハ延燒無之、妄說之由こい。二月十日晴.夕風。先日江戶大火之燒跡書來ル。大名二十九軒、旗本御家人九百十三軒、寺院五軒、社二軒町家
